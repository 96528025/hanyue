# 汉跃 HANYUE

一款原创、可交互的普通话入门网页应用。体验借鉴了路径式短课、即时反馈、经验值和连续学习等语言学习产品的通用机制，品牌、视觉、课程内容和角色均为原创。

## 运行

```bash
npm start
```

然后打开 `http://localhost:4173`。

## 已实现

- 两个单元、八个路径节点及逐课解锁
- 选择、听力、组句、输入四种题型
- 即时判题、错题记录、竹能量、XP、连胜、每日目标
- 浏览器语音合成中文发音与答题音效
- 错题/能量练习、任务、排行榜
- localStorage 本地进度持久化
- 桌面、平板和手机响应式布局
- 键盘 Enter 操作、焦点样式和减少动效偏好
